\# System Requirements



\## 1. Hardware Requirements



\### Minimum



\- Processor: Intel Core i3 (8th Gen) or equivalent

\- RAM: 4 GB

\- Storage: 2 GB Free Space

\- Internet Connection



\### Recommended



\- Processor: Intel Core i5 (10th Gen or above)

\- RAM: 8 GB or more

\- SSD Storage

\- Stable Internet Connection



\---



\## 2. Software Requirements



\- Windows 10/11, Linux, or macOS

\- Python 3.13 or later

\- Git

\- Visual Studio Code

\- Google Chrome



\---



\## 3. Python Packages



The following packages will be used during development:



\- FastAPI

\- Uvicorn

\- Requests

\- python-whois

\- dnspython

\- BeautifulSoup4

\- Jinja2

\- Pydantic

\- python-dotenv



Additional packages may be added as the project grows.



\---



\## 4. External Services



The project may use the following APIs:



\- VirusTotal API

\- Google Safe Browsing API

\- PhishTank (Optional)



\---



\## 5. Development Environment



\- IDE: Visual Studio Code

\- Version Control: Git \& GitHub

\- Virtual Environment: Python venv
